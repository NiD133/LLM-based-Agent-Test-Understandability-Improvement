## The command

From your working directory, run exactly:

```bash
bash compile.sh
```

The script invokes `javac` on the test file you wrote to the output path,
writes `.class` files into `test-classes/`, and prints **one of two literal
strings** as the LAST line of stdout:

- `COMPILE_OK` (exit code 0)
- `COMPILE_FAIL (exit=<N>)` followed by the original `javac` stderr (exit ≠ 0)

Use that final line as your decision signal — do not paraphrase or
interpret the diagnostics beyond what the line tells you.

    private static void doEscape(String data, QuietAppendable accum, EscapeMode mode, Charset charset, int options) {

    private static void load(EscapeMode e, String pointsData, int size) {
        e.nameKeys = new String[size];
        e.codeVals = new int[size];
        e.codeKeys = new int[size];
        e.nameVals = new String[size];

        int i = 0;
        try (CharacterReader reader = new CharacterReader(pointsData)) {
            while (!reader.isEmpty()) {
                // NotNestedLessLess=10913,824;1887&

                final String name = reader.consumeTo('=');
                reader.advance();

                final char codeDelim = reader.current();
                reader.advance();
                final int cp2;

                    reader.advance();
                } else {
                    cp2 = empty;
                }

                final int index = Integer.parseInt(indexS, codepointRadix);
                reader.advance();

                e.codeVals[i] = cp1;
                e.codeKeys[index] = cp1;
                e.nameVals[index] = name;

                if (cp2 != empty) {
                    multipoints.put(name, new String(new int[]{cp1, cp2}, 0, 2));
                }
                i++;
            }

            Validate.isTrue(i == size, "Unexpected count of entities loaded");
        }
